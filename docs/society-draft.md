# ひだまり村 社会システム草案 v0.5

> 目的：お金・資産・組織・生存（食べられなければ死ぬ）を導入する。性格・仕事・秘密・組織・法律は**最初は何もない**。住民が自分で考えて、仕事に就き、辞め、組織を作り、ルールを決め、ときには何かを隠す。その過程で社会が形成されていく様子を観察する。

---

## 0. 設計の前提

| 制約 | 影響 |
|---|---|
| ローカルLLMは 1回 15〜30秒、同時に1件 | **全行動をLLMに決めさせるのは不可能**。LLMは「判断の要所」だけに使う |
| 7Bモデルは設定や数字を取り違える | LLMには**選択肢の中から選ばせる**。お金・在庫・生産量の計算は必ずプログラムが行う |
| 見ている間だけ時間が進む（等速で1日＝12分） | 1日あたりのLLM呼び出しは **20〜30回程度** が上限の目安 |

### 3層の意思決定

```
┌──────────────────────────────────────────────────────────┐
│ ③ LLM：人生の判断  ── 1日1回の「朝の計画」／危機のとき／会話の中の合意／会合 │
├──────────────────────────────────────────────────────────┤
│ ② ルール：計画の実行 ── 計画を時間割に落とし、移動・生産・売買を実行          │
├──────────────────────────────────────────────────────────┤
│ ① 物理：生理と経済の計算 ── 空腹・体力・お金・在庫・熟練度を毎分更新         │
└──────────────────────────────────────────────────────────┘
```

- LLMが使えない・混んでいるときは、③を**ルールベースの代替プランナー**が肩代わりする（「食べ物が少なければ畑か川へ」程度。村は止まらない）。
- LLMの出力は必ず**検証**してから反映する（存在しない行動・払えない金額は却下）。

## 1. 初期状態：完全にフラットな村

**全員がまったく同じ条件**から始まる。違うのは名前と見た目だけ。

| 項目 | 初期値 |
|---|---|
| 所持金 | 全員 100G |
| 食べ物 | 全員 パン2・野菜3（約1日半ぶん） |
| 家 | 1人1軒（自分の家だけは所有している） |
| 性格 | **なし** |
| 仕事 | **なし** |
| 秘密 | **なし** |
| 熟練度 | 全員すべて 0 |
| 人間関係 | 全員「顔見知り」、好感度 0 |
| 組織・法律 | **なし**（村の金庫もない） |

### LLMに先入観を与えないために

- **名前**は性別や年齢を連想させにくいもの（例：ハル、ソラ、アオイ、ユウ、レン、マコト）にする。
- **年齢・性別はプロンプトに渡さない**。見た目（ドット絵）は区別のためだけに使い、LLMには伝えない。
- 6人で始める。

### 個性はどこから生まれるか

全員が同じだと、LLMは全員に同じ行動をさせがちになる。差は次の偶然から生まれ、経験として積み重なる。

| 差の源 | 例 |
|---|---|
| 家の位置 | 畑に近い家、川に近い家、広場に近い家 |
| 運 | 釣れる・釣れない、作物の出来 |
| 出会い | 誰と、いつ、どこで会ったか |
| LLMの出力のぶれ | 同じ状況でも毎回少し違う判断をする |
| 積み重ね | 熟練度、持ち物、記憶、人間関係 |

- **自己像**：数日に1回、本人の記憶と行動の記録からLLMに「自分はどういう人間か」を短くまとめさせ、以後のプロンプトに渡す。**性格は与えるのではなく、育つ**。
  例：「釣りが得意で、人に物を分けるのが好き。ただし約束を破る人は許さない」
- 心タブでは自己像の移り変わりを見られる（観察の目玉のひとつ）。

## 1.5 人口の出入り

- **新入村民**：村の外から、同じくフラットな状態（名前・見た目だけ、所持金は少なめ）でやってくる。
  - 来る頻度は**村の状態で変わる**：食糧に余裕があり、豊かで、治安が良い（非行が少ない）ほど人が来やすい。
  - 新入村民は村の外の噂（「隣の村では〜」）を持ち込むこともある。
  - 神の力でも呼べる。
- **離村**：住民は行動として「村を出る」を選べる（飢えそう、居場所がない、嫌われている、など）。出て行った人の資産は家に残る。
- 空き家が足りなくなったら、新入村民は**家を建てる**（材料とお金がかかる）か、誰かの家に間借りする（合意が必要）。

## 2. 生存（食べないと死ぬ）

| 値 | 範囲 | 変化 |
|---|---|---|
| 満腹度 `satiety` | 0〜100 | 起きている間 -4/時、寝ている間 -2/時（1日で約 -80） |
| 体力 `health` | 0〜100 | 満腹度0の間 -4/時。満腹度50以上なら +1/時で回復 |

- 満腹度30未満：「空腹」。会話や判断に影響（不機嫌、食べ物の話ばかり）
- 満腹度0：「飢え」。体力が減り始め、この状態が続くと約1日で死亡する
- 体力0：**死亡**。お墓が建ち、ニュースとして村じゅうに伝わり、関係の深かった人の記憶に強く残る
- 遺産：遺言（会話の合意で残せる）→ 所属組織の規約 → どちらも無ければ「持ち主のいない物」として家に残る（拾う・奪うのは自由。それ自体が事件になる）
- 人口の増減は 1.5節を参照

## 3. 経済

### 3-1. 設備（最初は共有）

建物や畑は「職場」ではなく**設備**。最初は誰のものでもなく、誰でも使える。

| 設備 | できること | 同時に使える人数 |
|---|---|---|
| 畑 | 畑仕事 → 小麦・野菜 | 3 |
| 釣り場（川沿い） | 釣り → 魚（運次第） | 2 |
| パン焼き小屋（今のパン屋） | 小麦 → パン | 1 |
| 食堂（今の酒場） | 野菜＋魚 → 定食 | 2 |
| 集会所（今の学校） | 会合・集会 | 全員 |

- 人数を超えると使えない → **場所の取り合い**が起きる。
- 誰かが「ここは自分の店だ」と言い張ったり、組織で買い取ったり、法律で所有を決めたりすると**所有者が生まれる**（後述）。

### 3-2. 生産と熟練度

```
 畑仕事 1時間 ──▶ 小麦 1.0 × 熟練係数、野菜 0.8 × 熟練係数
 釣り   1時間 ──▶ 魚 0〜2（運）× 熟練係数
 パン焼き      ──▶ 小麦1 → パン 1〜2（熟練するほど2に近づく）
 料理          ──▶ 野菜2＋魚1 → 定食1（熟練が低いと失敗して材料が無駄になる）
```

- 熟練度は**やればやるほど上がり**、やらないと少しずつ下がる。熟練係数は 0.5（素人）〜 1.5（達人）。
  → 最初は全員下手で、続けた人が上手くなる。**分業が自然に生まれる**仕組み。

| 食べ物 | 満腹度 | 腐るまで |
|---|---|---|
| 小麦 | （そのままでは食べられない） | 腐らない |
| 野菜 | +15 | 3日 |
| 魚 | +25（生でも食べられる） | 1日 |
| パン | +30 | 2日 |
| 定食 | +50 | その日のうち |

- 「全員が畑と釣りで自給自足」も可能だが効率が悪い。パンや定食に加工すると、同じ材料で満腹度が増える。**加工する人と、材料を作る人に分かれた方が得**になるよう数値を調整する。

### 3-3. お金

- 単位は **G**。**村の中で総量を保存**する（勝手に増えも減りもしない）。
- 外との出入り口は**行商人**だけ（ときどき来て、余った物を買い取り、外の品を売る）。
- 価格は売り手が**自由に**決める。こちらから基準の値段は見せない。LLMに見せるのは「実際に売れた値段の平均（相場）」だけで、取引がまだなければ「相場はまだない」と伝える。
- **インフレは容認する**（商売を後押しするため）。値段に上限はない。ただしお金の総量は保存されているので、値段が上がるほど買える人は限られる。
- 買い手にも「出してもいい値段」がある：空腹なほど、お金を持っているほど高くても買う（満腹なら安くないと買わない）。飢えた人に高値で売る商売も成り立つ。
- 欲しかったのに高くて買えなかったことは、買い手の記憶に残る（不満の種）。

### 3-4. 仕事とは

- 「仕事」は**本人が名乗るもの**。朝の計画で「今日からパン屋をやる」と決めれば、その人はパン屋を名乗る。
- 実際に何をしているかは行動の記録に残る。**名乗っている仕事と実際の行動が食い違うこともある**（パン屋を名乗りながら、実は盗んだ小麦を使っている、など）。
- 店を開く：設備で作った物に値段をつけて、その場で売る（本人がいる間だけ開店）。
- 雇う・雇われる：会話の合意で決まる（日給・場所・期間）。

## 4. LLMが決めること

### 4-1. 朝の計画（1人1日1回、起床時）

渡す情報：**自己像**、満腹度、体力、所持金、持ち物、名乗っている仕事、熟練度、雇用・貸し借り、所属組織、好感度、最近の記憶、ニュース、法律（あれば）、**今日できる行動の一覧**。

```json
{
  "occupation": "パン屋",
  "goal": "パンを多めに焼いて売り、源さんから小麦を安く仕入れる約束を取りつける",
  "blocks": [
    { "from": 6, "to": 11, "action": "craft", "place": "bakery", "item": "パン" },
    { "from": 11, "to": 13, "action": "sell", "place": "bakery", "prices": { "パン": 12 } },
    { "from": 13, "to": 14, "action": "eat" },
    { "from": 14, "to": 16, "action": "visit", "target": "源さん", "purpose": "小麦の仕入れ交渉" }
  ]
}
```

- `occupation` を変える＝転職。空にすれば無職。
- `action` は**行動カタログ**から選ぶ。カタログにない行動、前提条件を満たさない行動は却下し、代替プランナーで埋める。

### 行動カタログ（初期）

| action | 前提条件 | 効果 |
|---|---|---|
| `farm` / `fish` | 設備が空いている（所有者がいれば許可が要る） | 材料を作る |
| `craft` | 材料がある、設備が空いている | パン・定食を作る |
| `sell` | 品物がある | その場で店を開く |
| `buy` | お金がある、開いている店がある | 買う |
| `eat` | 食べ物がある | 満腹度が上がる |
| `work_for` | 雇用の合意がある | 雇い主の設備で働き、日給をもらう |
| `visit` | 相手がいる | 会いに行く（交渉・相談・謝罪・脅し） |
| `wander` | なし | ぶらつく（出会い・噂を探す） |
| `rest` | なし | 家で休む |
| `meeting` | 組織に属している | 組織の会合に出る |
| `steal` | 対象の持ち主がその場にいない | 盗む。誰かに見られる可能性がある |
| `hide` | 盗品など隠したい物がある | 隠す（見つかりにくくなる） |
| `leave_village` | なし | 村を出て行く（二度と戻らない） |

### 4-2. 会話の中の「合意」

会話の結果として成立した約束を、会話生成のJSONに `agreements` として出力させる。

| type | 内容 |
|---|---|
| `trade` | 物とお金の交換 |
| `gift` | 贈与・施し |
| `loan` / `repay` | 貸し借り・返済 |
| `hire` / `quit` | 雇う・辞める |
| `claim` | 設備の所有・使用権を認める／譲る（「パン焼き小屋はミカのものでいい」） |
| `found_org` / `join_org` / `leave_org` | 組織の結成・加入・脱退 |
| `hush` | 口止め（知っていることを黙っている約束。見返りつきもある） |
| `promise` | その他の約束（守られたかどうかを後で判定する） |

- システムが実行できるかを検証する。お金が足りなければ不成立になり、「払えなかった」という記憶が残る。

### 4-3. 危機の判断（臨時）

満腹度が20未満で、食べ物も買うお金も無いとき、その場でLLMに選ばせる：頼る／借りる／物を売る／盗む／施しを求める／何もしない。

### 4-4. 呼び出し回数の見積もり（6人）

| 種類 | 回数/日 |
|---|---|
| 朝の計画 | 6 |
| 会話（合意つき） | 10〜15 |
| 危機の判断 | 0〜3 |
| 組織の会合・集会 | 0〜2 |
| 神様AI | 2〜3 |
| **合計** | **約20〜30**（1日12分 ÷ 20秒 ≒ 36回 なので収まる） |

## 5. 組織と法律（最初は無い）

### 組織

```ts
interface Organization {
  id: string;
  name: string;            // 住民が名づける
  purpose: string;         // 設立の目的（LLMが書く）
  members: { id: string; role: string }[];  // 役職名も住民が決める
  treasury: number;        // 組織の金庫
  dues: number;            // 会費
  rules: string[];         // 組織内の決まり（自然言語）
  assets: string[];        // 所有する設備
  public: boolean;         // 存在を公にしているか（秘密結社もありうる）
}
```

- **結成**：会話の合意（`found_org`）で2人以上が賛成すると成立。種類は決めない（商店、組合、互助会、自治会、秘密の結社…何になるかは住民次第）。
- **会合**：代表が呼びかけたとき。LLMが方針を決める（会費、支援、事業、除名、設備の買い取り）。

### S5（第1段階）での実装：村の集会（2026-10-03）

- 行動 `call_assembly`（集会を呼びかける）。議題（purpose）と、相手（target）があれば指定する。広場で呼びかけると、その日の18〜19時半（間に合わなければ翌日）に集会所で集会が開かれ、全員が集まる。予定がある間は次の集会は呼びかけられない。
- 集会では、AI1回で全員の発言（3〜6人）・提案・投票（全員）を生成する。各人には、その人が知っていること・隠していること・呼びかけた人と相手への気持ちだけを渡す。
- 提案は `exile`（追放）・`fine`（罰金。受け取る人がいなければ村のみんなで分ける）・`rule`（決まりを作る）・`repeal`（決まりをやめる）・`none`（話し合いだけ）。出席者の過半数が賛成すれば可決し、仕組みが実行する。
- 罰を受けた人は、賛成した人への好感度が下がる。全員に、自分の投票と結果が記憶として残る。
- 決まりは、計画・会話のプロンプトと、神の力タブに表示される。守らせる仕組み（罰則の自動執行）はまだなく、守るかどうか・破った人をどうするかは、村人と次の集会しだい。
- まだないもの：組織（結成・会費・役職）、決まりの数値パラメータ（税・罰金の自動化）、裁判の手続き。

### 法律

- 最初は**法律も自治の仕組みもない**。盗んでも罰はなく、あるのは評判と人間関係だけ。
- 誰かが「村全体の決まりが必要だ」と考えて**全員参加の組織**を作り、そこで決めたことが法律になる。
- 法律は「仕組みが強制する数値」と「LLMが解釈する条文」の2種類を持つ。

```ts
interface Law {
  id: string;
  title: string;
  text: string;            // 条文。判断や裁判のときにLLMへ渡す
  params?: {               // 仕組みが直接使う数値（あれば）
    taxRate?: number;
    theftFineMultiplier?: number;
    exileAfterOffenses?: number;
    welfarePerDay?: number;
  };
  enactedBy: string;       // 決めた組織
  enactedDay: number;
}
```

- **改定**：その組織の集会（LLM1回で全員の発言と投票をまとめて生成）で可決されれば改定・廃止される。
- **裁判**：告発があれば集会で審理する。証言（誰が何を知っているか）と条文をLLMに渡して判決を出させ、罰金・追放などの執行は仕組みが行う。

## 6. 隠せる非行と「知っていること」

秘密は最初は無いが、**行動から生まれる**。そのために「誰が何をして、誰がそれを知っているか」を仕組みとして持つ。

```ts
interface Deed {
  id: string;
  actor: string;
  kind: 'steal' | 'embezzle' | 'fraud' | 'lie' | 'bribe' | 'break_promise';
  victim?: string;
  amount?: number;
  item?: string;
  at: number;
  placeId: string;
  knownBy: Set<string>;               // 知っている人（最初は本人だけ）
  suspectedBy: Map<string, number>;   // 疑っている人と疑いの強さ
  exposed: boolean;                   // 公になったか
}
```

```
 実行 ──▶ 同じ場所に人がいた／通りかかった ──▶ その人が「知っている」
   └──▶ 被害者が在庫やお金の減りに気づく ──▶ 「何かおかしい」と疑う（犯人は不明）

 知っている人・疑っている人は、会話の中で
   黙る／本人をゆする／他の人に話す／組織や集会に訴える
 を選ぶ（自己像と人間関係からLLMが決める）。
 隠す側は、口止め（hush）・嘘・なすりつけ・盗品を隠す（hide）を選べる。
```

- 行為をした本人の朝の計画や会話のプロンプトには「自分が隠していること」として渡す。**秘密はこうして後から生まれる**。
- 人づてに伝わるうちに確度が下がる（「〜らしい」）。
- 心タブでは神の視点で、本人が隠していることと、それを誰が知っているかを見られる。

---

### S4での実装（2026-10-02）

- 行動：`steal`（こっそり盗む）・`rob`（力ずくで奪う）・`attack`（殴る）・`kill`（殺す）・`accuse`（広場で言いふらす。本当でも嘘でもよい）。夜の計画で選べる。飢えたときの判断では `steal`・`rob` も選べる。
- 成否：盗みは必ず成功（相手が何か持っていれば、いちばん価値のある食べ物の半分、なければお金の半分）。奪う・殺すは体力の差（＋相手が寝ているか）で決まる。殺しそこねると相手は傷を負う。殴ると体力が20〜45減り、0になれば死ぬ。
- 目撃：その場（屋内なら同じ建物、屋外なら7マス以内）にいた人が、盗みは5割、暴力は9割の確率で見る。盗まれた本人がその場で気づくのは35%。気づかなかったときは30〜120分後に「なくなっている」と気づき、**そのころ近くにいた人の名前**だけが記憶に残る（無実の人も混ざる）。
- 記録：`Deed`（誰が・誰に・何を・どこで・誰が知っているか・口止めされた人・公になったか）。本人の計画と会話には「隠していること」、ほかの人には「知っていること」として番号つきで渡す。
- 広まり方：会話のあとの書き出しで、番号つきの出来事を相手に話したか（`disclosures`）を判定し、聞いた人も知る。広場で言いふらしたことが本当なら、村じゅうが知る。
- 口止め：会話の合意 `hush`（口止め料つきでもよい）。約束を守るかどうかは本人しだい。
- 気持ち：やられた人・見た人・聞いた人の、相手への好感度が理由つきで下がる。
- 神の視点：ログに「誰が何をしたか（見ていた人）」がすべて出る。心タブでは本人の隠していることと、本当に知っている人が見える。

## 6.5 負の感情・暴力・追放

方針：**負の感情を「必ず起こす」仕組みは入れない**（操作になるため）。代わりに、

1. **穏便に寄せる偏りを外す**（LLMは放っておくと仲良くまとめがち）
2. **負の感情の材料を正直に見せる**
3. **感情が行動になる手段を用意する**

の3つで、理由があるときに自然に生まれるようにする。

### 1. 偏りを外す（S2で実施済み）

- 会話：「無理に仲良くさせない。理由があれば不満・嫉妬・恨み・怒り・軽蔑も自然に出してよい。理由がないのに対立させる必要もない」
- 計画の本音：「取り繕わずに書く。不安・不満・嫉妬・恨みがあればそのまま書いてよい」

### 2. 材料を見せる（観察できる事実だけ）

| 事実 | 生まれうる感情 |
|---|---|
| 自分は飢えているのに、相手は食べ物を余らせて売り残している | 嫉妬・恨み |
| 設備が満員で、いつも同じ人に使われている | 不満 |
| 貸したお金が返ってこない／約束が破られた | 怒り・不信 |
| 頼みを断られた、高値で売りつけられた | 恨み |
| 誰かが盗んだのを見た、噂を聞いた | 軽蔑・恐れ |
| 身近な人が飢え死にした | 悲しみ・怒り（誰に向くかは本人次第） |

- これらは記憶と「相手への気持ち」に残す。気持ちは数値だけでなく**理由つき**で持つ（「恨み：3日目、パンを分けてくれと頼んだのに断られた」）。

### 3. 行動の手段

**暴力**（S4で「非行」と一緒に入れる）

| action | 内容 | 結果 |
|---|---|---|
| `confront` | 詰め寄る・脅す | 会話が強制的に始まり、相手が要求をのむか拒むか（LLM） |
| `rob` | 力ずくで奪う | 相手の持ち物・お金を奪う。体力の差で成否が決まる。相手は覚えている |
| `attack` | 殴る | 相手の体力を大きく減らす。体力0なら死亡 |
| `kill` | 殺す | 成功すれば相手は死ぬ（死因「殺された」） |

- 前提：相手と同じ場所にいる。目撃者がいるかどうかで、その後が大きく変わる。
- 目撃者がいなければ、遺体が見つかっても「何者かに殺された」とだけ村に伝わる。疑い・噂・告発は 6節の仕組みで広がる。
- 体力が落ちている人は抵抗できない → 弱った人が狙われるという残酷さも生まれうる。

**追放**

- 誰でも「村の集会」を呼びかけられる（`call_assembly`、議題つき）。集会所に全員が集まり、LLM1回で発言と投票をまとめて生成する。
- 議題の例：「○○を追放する」「盗みをした者には罰を与える」「畑の使い方を決める」。
- 過半数で可決すれば実行される。追放された人は村を出なければならない（拒めば、それ自体が新しい対立になる）。
- 組織と法律ができる前の、**いちばん原始的な自治**として位置づける。集会が繰り返されると、やがて常設の組織（自治会）や法律が生まれるかもしれない。
- 集会を呼びかける力、票を集める力は人によって違う → 個人差がそのまま政治的な力になる（リーダーにも独裁者にもなりうる）。

## 6.8 その後に入れた仕組み（2026-10-03〜05）

### 欲
- **望み**：自己像と一緒に、経験から「いつか〜したい」を生成。計画・会話・集会の判断材料。
- **木材と家の改築**：森で木を切る → 木材で家を改築（4段、地図の見た目が変わる）。改築すると村の全員から一目置かれる（好感度が上がる）。
- **お酒**：小麦2から食堂で造る。夜に家で飲むと暮らしの満足が上がる。
- **暮らしの満足**：食事の種類・お酒・会話・家の比べっこで毎晩見直す。仕事のはかどりに響く（0.9〜1.2倍）。

### 非行の得と、秘密・噂
- 取り分：盗む＝食べ物それぞれ半分とお金3割、奪う＝食べ物すべてとお金半分、殺す＝すべて。
- 秘密を話すと起こりうること（恨まれる・広まる・罰）を本人に見せる。
- **噂の変質**：人づてに伝わるとき、また聞きは35%で犯人が別人になるか量が3倍になる。恨みは聞いた話の犯人へ向かう（冤罪が生まれる）。

### 教える商売
- 教わるには必ず代金（会話で決めた額か、最低で上達の幅×10G）。上達は腕前の差の4割。

### 組織（S5の続き）
- 会話の合意で作る・入る・抜ける。名前・目的・会費は村人が決める。毎晩会費が金庫へ。代表は金庫から払える。代表がいなくなれば古いメンバーが継ぐ。

### 季節・盗賊
- 3日ごとに春夏秋冬（12日で1年）。秋は畑1.3倍、冬は畑0.2倍・釣り0.5倍・お腹の減り1.25倍。
- 盗賊：前の日に知らせ、夜20時に来る。見張りが多く元気なら追い払える（一目置かれる）。だめなら村じゅうの持ち物の3割を奪われる（お金は村の外に出ない）。

### 遺品・信仰
- 亡くなった（出ていった）人の物は空き家に残り、誰でも持ち出せる（見られれば盗みに見える）。集会で行き先を決められ、越してきた人は残っていた物を受け継ぐ。
- 天の声を聞いた人は祈る・説くことができ、説かれた人も祈れる。祈りは神の力タブに届き、「応える」で天の声を返せる。

### 知り得ない情報は渡さない
- 人の持ち物と様子は、最後に会ったとき（会話・市場）に見たものしか分からない。記録係のAIと神の視点だけはすべて見える。

### 検証で分かったこと（qwen2.5:7b）
- 満ち足りた村でも、望みや小さな摩擦から盗みは起きる。飢えて追い詰められると、むしろ人に頼る（奪うことを考えて、危険だとやめることもある）。
- 盗んだ本人はすぐ人に打ち明けがち。噂はゆがみ、冤罪や言いふらしが生まれる。
- 集会は自分から開くが、議題は繰り返しがち（自然な流れとして残す）。組織はなかなか自発的には生まれない。

## 9. 決定事項

- 死：**本当に死ぬ**
- お金：**村の中で総量を保存**（外との出入りは行商人のみ。新入村民は無一文）
- 価格：**売り手が自由に決める。基準の値段は見せない。インフレ容認**
- 住民：**完全にフラット**。違うのは名前と見た目だけ。性格・年齢・性別はLLMに渡さない
- 個性：**経験から育つ**（自己像を定期的に生成）
- 人口：新入村民は村の豊かさに応じて来る。住民は村を出ることもできる
- 仕事・秘密・組織・法律：**最初は何もない**。住民が自分で作る
- 法律：作られたあとは**改定できる**
- 非行：**あり、隠せる**
- 負の感情：**強制はしない**。偏りを外し、材料を見せ、行動の手段（暴力・殺人・追放）を用意する
- 追放：村の集会の多数決で決まる（組織や法律ができる前の原始的な自治）
- 個人差：**歓迎する**。差がリーダーや独裁者を生む経路（雇用・貸し借り・集会・組織）を用意する
- LLMに任せる範囲：朝の計画＋会話の合意＋危機の判断＋会合・集会＋自己像
